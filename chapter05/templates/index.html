Глава 5: Jinja2 basics

Минимальные серверные шаблоны: переменные, условие if, цикл for и передача данных из FastAPI в HTML.

Порт: 8005 Swagger: http://localhost:8005/docs Результат: После главы вы понимаете, как Python готовит данные, а Jinja2 показывает их через {{ }}, {% if %} и {% for %}.

Что разбираем в этой главе

  • Jinja2Templates - подключение папки HTML-шаблонов.
  • TemplateResponse - ответ, который рендерит шаблон на сервере.
  • context - обычный Python-словарь с данными для шаблона.
  • {{ variable }} - вставка значения переменной в HTML.
  • {% if condition %} - показать кусок HTML только при выполнении условия.
  • {% for item in items %} - повторить кусок HTML для каждого элемента списка.

Как проходит запрос

  1. Пользователь открывает /jinja-demo.
  2. Endpoint собирает простой словарь: заголовок, имя ученика, список тем и флаг подсказки.
  3. FastAPI вызывает templates.TemplateResponse(...).
  4. Jinja2 открывает файл jinja_demo.html и подставляет значения из словаря.
  5. {{ title }} печатает одну строку.
  6. {% if show_hint %} решает, показывать ли блок подсказки.
  7. {% for topic in topics %} создаёт один пункт списка для каждой темы.
  8. Браузер получает уже готовый HTML. В браузере Python-код не выполняется.

Endpoint-ы для проверки

GET /Страница урока.
GET /jinja-demoМинимальная HTML-страница с переменными, if и for.
GET /api/template-dataТе же данные в JSON, чтобы сравнить Python-словарь и HTML-вывод.

Если совсем по-простому

До этого мы в основном возвращали JSON. Здесь FastAPI возвращает обычную HTML-страницу.

Jinja2 - это шаблонизатор: HTML-файл с местами, куда сервер подставляет данные.

Самая простая схема такая: Python создаёт словарь, Jinja2 берёт значения из словаря и вставляет их в HTML.

В этой главе мы специально не трогаем формы, регистрацию и сложную валидацию. Сначала нужно понять переменные, if и for.

Построчный разбор

LESSON_TOPICS
Обычный Python-список словарей. Его удобно выводить циклом в HTML.
templates.TemplateResponse(...)
Говорим FastAPI: возьми HTML-файл, подставь данные и верни готовую страницу.
"topics": LESSON_TOPICS
Ключ topics станет доступен в шаблоне как переменная topics.
{{ title }}
Две фигурные скобки печатают значение переменной.
{% if show_hint %}
Конструкция с процентами не печатает текст, а управляет логикой шаблона.
{% for topic in topics %}
Цикл берёт список topics и по очереди кладёт каждый элемент в переменную topic.

Что здесь важно

  • Python здесь отвечает за данные: он создаёт строки, список и флаг show_hint.
  • Jinja2 отвечает за отображение: где напечатать строку, где повторить блок, где спрятать блок.
  • HTML в этой главе специально простой. Главная тема - связь endpoint-а и шаблона.

Типичные ошибки новичков

  • Забыть передать request в context. Для Starlette/FastAPI templates он нужен.
  • Назвать ключ в Python homework_steps, а в шаблоне случайно написать homework_step. Jinja2 не найдёт такую переменную.
  • Писать в шаблоне Python-синтаксис for step in homework_steps:. В Jinja2 нужно {% for step in homework_steps %}.

2. Куда положить HTML-файл и какой адрес открыть

Ошибка TemplateNotFound: 'jinja_demo.html' означает, что Python-код запустился, но Jinja2 не нашёл файл шаблона на диске.

  • В учебнике файл лежит здесь: chapter05/templates/jinja_demo.html.
  • Если вы копируете пример в свой проект и файл Python находится в FastApiLearning/5/main.py, то при строке BASE_DIR = Path(__file__).resolve().parent.parent шаблон нужно положить сюда: FastApiLearning/templates/jinja_demo.html.
  • То есть рядом с папкой 5 должна быть папка templates, а внутри неё файл jinja_demo.html.
  • Если хотите хранить шаблон внутри FastApiLearning/5/templates/jinja_demo.html, тогда в коде нужно заменить parent.parent на parent.
  • После запуска сервера HTML-страница открывается в браузере по URL http://localhost:8005/jinja-demo. Если вы запускаете свой пример на другом порту, замените 8005 на свой порт.

{% raw %}from pathlib import Path

from fastapi import FastAPI, Request
from fastapi.responses import HTMLResponse, RedirectResponse
from fastapi.templating import Jinja2Templates


BASE_DIR = Path(__file__).resolve().parent.parent

LESSON_TOPICS = [
    {
        "name": "Переменная",
        "template": "{{ title }}",
        "description": "Jinja2 берёт значение из context и вставляет его в HTML.",
    },
    {
        "name": "Условие if",
        "template": "{% if show_hint %}",
        "description": "Блок показывается только тогда, когда значение истинное.",
    },
    {
        "name": "Цикл for",
        "template": "{% for topic in topics %}",
        "description": "Один HTML-фрагмент повторяется для каждого элемента списка.",
    },
]

HOMEWORK_STEPS = [
    "Открыть страницу /jinja-demo",
    "Найти блок Домашние шаги",
    "Сравнить пункты на странице с Python-списком",
]

app = FastAPI(
    title="Глава 5: Jinja2 basics",
    description="Templates, variables, if, for",
    version="1.0.0",
    docs_url="/docs",
    redoc_url="/redoc",
)
templates = Jinja2Templates(directory=str(BASE_DIR / "templates"))


@app.get("/", response_class=HTMLResponse, include_in_schema=False)
async def index(request: Request):
    return templates.TemplateResponse(request, "index.html", {"request": request})


@app.get("/swagger", include_in_schema=False)
async def swagger():
    return RedirectResponse(url="/docs")


def demo_context(request: Request) -> dict:
    return {
        "request": request,
        "title": "Jinja2 demo",
        "student_name": "Анна",
        "topics": LESSON_TOPICS,
        "homework_steps": HOMEWORK_STEPS,
        "show_hint": True,
    }


@app.get("/jinja-demo", response_class=HTMLResponse, include_in_schema=False)
async def jinja_demo(request: Request):
    return templates.TemplateResponse(request, "jinja_demo.html", demo_context(request))


@app.get("/api/template-data")
async def template_data():
    return {
        "title": "Jinja2 demo",
        "student_name": "Анна",
        "topics": LESSON_TOPICS,
        "show_hint": True,
    }{% endraw %}

5. Как проверить

Файл шаблонаПеред запуском существует файл templates/jinja_demo.html в той папке, которую ищет Jinja2Templates.
GET /jinja-demoНа странице есть блок Домашние шаги и три пункта из списка.
GET /api/template-dataJSON остаётся базовым и не содержит homework_steps.

Полный разбор ответа

Ниже решение разобрано по частям: что стоит на своём месте, зачем это нужно и какие ошибки чаще всего появляются, если часть кода пропустить.

Что именно добавляем в Python

В Python-части не нужно создавать новую страницу, форму или модель. Нужно только подготовить ещё один список и положить его в context.

  • HOMEWORK_STEPS - обычный Python-список строк. В нём нет магии Jinja2.
  • Ключ homework_steps добавляется в словарь, который возвращает demo_context.
  • /api/template-data специально не меняется, чтобы код урока и код ответа не сливались в одно и то же.
  • Endpoint /jinja-demo не меняет бизнес-логику: он просто передаёт шаблону обновлённый context.

Что именно добавляем в шаблон

  • Новый блок начинается с обычного заголовка <h2>Домашние шаги</h2>.
  • <ol> означает нумерованный список. Это базовый HTML: браузер сам поставит 1, 2, 3.
  • {% for step in homework_steps %} говорит Jinja2: возьми список homework_steps и перебери его.
  • <li>{{ step }}</li> печатает один пункт списка.
  • {% endfor %} закрывает цикл. Без закрытия Jinja2 не поймёт, где заканчивается повторяемый кусок.

Как работает for

  • Если в списке три строки, HTML-блок внутри цикла появится три раза.
  • На первом проходе step равен первой строке списка.
  • На втором проходе step равен второй строке списка.
  • На третьем проходе step равен третьей строке списка.
  • После последнего элемента Jinja2 выходит из цикла и продолжает читать шаблон ниже.

Как проверить

  • Откройте http://localhost:8005/jinja-demo и найдите блок Домашние шаги.
  • Если видите TemplateNotFound, сначала проверьте путь к файлу: для такого кода Jinja2 ищет templates/jinja_demo.html относительно BASE_DIR.
  • Проверьте, что на странице видны все три пункта из HOMEWORK_STEPS.
  • Откройте http://localhost:8005/api/template-data и проверьте, что там нет homework_steps.
  • Если JSON содержит homework_steps, значит вы случайно перенесли ответ не только в шаблонную часть, но и в API endpoint.

Читаем простой Jinja-ответ сверху вниз

  • Path нужен только для аккуратного пути к папке templates в этой HTML-главе.
  • LESSON_TOPICS и HOMEWORK_STEPS - обычные списки Python. Они могли бы прийти из базы данных, но для обучения список проще.
  • FastAPI(...) создаёт приложение так же, как в API-главах.
  • Jinja2Templates(...) говорит FastAPI, где искать HTML-файлы.
  • demo_context собирает все данные страницы в одном месте, чтобы endpoint оставался коротким.

Что происходит при GET /jinja-demo

  • Браузер просит адрес /jinja-demo.
  • FastAPI находит функцию jinja_demo по decorator @app.get("/jinja-demo").
  • Функция вызывает demo_context(request) и получает словарь с title, student_name, topics, homework_steps и show_hint.
  • TemplateResponse берёт файл jinja_demo.html.
  • Когда Jinja2 видит {{ title }}, он ищет ключ title в словаре и печатает значение.
  • Когда Jinja2 видит {% if show_hint %}, он проверяет значение show_hint. У нас там True, поэтому подсказка появляется.
  • Когда Jinja2 видит {% for step in homework_steps %}, он повторяет HTML для каждого пункта списка.

Почему for лучше копирования HTML

  • Без цикла пришлось бы руками писать три одинаковых <li>.
  • Если завтра пунктов станет пять, без цикла придётся редактировать HTML вручную.
  • С циклом меняется только Python-список. Шаблон остаётся таким же.
  • Это главный смысл серверных шаблонов: данные живут в Python, а внешний вид живёт в HTML-файле.
  • Для новичка важно запомнить разделение: endpoint не должен собирать HTML строками, а шаблон не должен делать сложную бизнес-логику.

Короткое резюме решения

  • Список добавляется в context рядом с topics.
  • В шаблоне нужен обычный Jinja-цикл: открыть {% for %}, вывести {{ step }}, закрыть {% endfor %}.
