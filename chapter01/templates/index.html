Глава 1: Начало работы с FastAPI

Как работает REST API, зачем нужен Uvicorn, как FastAPI принимает JSON-запрос и возвращает JSON-ответ.

Порт: 8001 Swagger: http://localhost:8001/docs Результат: После главы вы понимаете полный путь REST-запроса, умеете запустить FastAPI через Uvicorn и прочитать учебный main.py без подсказок из исходников.

Как пользоваться этой главой

Эта глава показывает самый маленький полезный FastAPI-сервис целиком: приложение, запуск через Uvicorn, маршруты, входную модель, middleware, ручную бизнес-проверку и JSON-ответ.

REST API - это договор между клиентом и сервером. Клиент говорит: method, path, headers, body. Сервер отвечает: status code, headers, body.

Не пытайтесь сразу запомнить все декораторы. Сначала поймите цепочку: Uvicorn принимает HTTP-запрос, FastAPI выбирает функцию по method и path, Pydantic проверяет JSON, функция возвращает словарь.

После этой главы вы должны уметь прочитать показанный на странице main.py сверху вниз и объяснить, зачем нужна каждая часть: импорты, app, Uvicorn, модель, middleware и endpoint-ы.

Если вы только начинаете: не перепрыгивайте сразу к ответу. Сначала запустите пример, затем откройте код рядом с этой страницей и проговаривайте каждую строку обычными словами.

Учебный план

  1. На вкладке Разбор кода прочитайте полный учебный main.py сверху вниз: от импортов до запуска Uvicorn.
  2. На вкладке Теория сопоставьте REST-термины с реальным запросом: method, path, headers, body, status code и response body.
  3. Откройте Swagger UI и выполните все endpoint-ы из блока проверки. У каждого запроса поменяйте входные данные минимум два раза.
  4. Выполните curl-примеры с -i, чтобы увидеть не только JSON, но и HTTP status code с headers.
  5. Вернитесь на вкладку Практика, выполните лёгкое задание, затем среднее. Сложное задание можно оставить как самостоятельную мини-работу.
  6. Запустите тесты этой темы: tests/test_chapter01_calculator.py.

Что разбираем в этой главе

  • REST - стиль построения API, где клиент обращается к понятным URL, использует HTTP-методы и получает ответ со status code.
  • HTTP request - запрос клиента: method, path, headers и иногда body. Например: POST /api/calculator/add с JSON-телом.
  • HTTP response - ответ сервера: status code, headers и body. Например: 200 OK и JSON {"result": 15}.
  • HTTP method - действие запроса. GET обычно читает данные, POST отправляет данные на сервер.
  • Path - адрес внутри сайта или API. В http://localhost:8001/api/calculator/add path - это /api/calculator/add.
  • JSON body - данные, которые клиент отправляет серверу. В этой главе body выглядит так: {"a": 10, "b": 5}.
  • Header - строка служебной информации в request или response. Header не является основными данными, но помогает клиенту и серверу договориться о формате, авторизации, кеше и других деталях.
  • Status code - короткий числовой итог запроса: 200 успех, 400 плохие данные клиента, 422 ошибка валидации, 500 ошибка сервера.
  • FastAPI app - объект приложения, который хранит маршруты, middleware и настройки документации.
  • Path operation - Python-функция с декоратором @app.get, @app.post и так далее.
  • Pydantic model - контракт входного JSON: какие поля обязательны и каких типов они должны быть.
  • Middleware - код вокруг каждого запроса. Он может логировать, добавлять заголовки или измерять время.
  • ASGI - интерфейс, по которому Uvicorn передаёт HTTP-запросы в FastAPI-приложение.
  • Uvicorn - сервер, который слушает порт, принимает HTTP-запросы из браузера или curl и передаёт их объекту app.
  • OpenAPI - схема API, из которой FastAPI строит Swagger UI на /docs.

REST без магии

REST API можно представить как набор адресов, куда клиент отправляет запросы. У каждого запроса есть действие: прочитать, создать, изменить или удалить данные.

В этой главе мы не создаём сложные ресурсы вроде users или orders, а делаем калькулятор. Но принцип тот же: у нас есть понятные URL, HTTP-метод POST, JSON-вход и JSON-ответ.

Важно: REST - это не библиотека и не отдельный сервер. Это способ договориться, как клиент и backend общаются через обычный HTTP.

Из чего состоит HTTP request

  • Method: что клиент хочет сделать. В примере это POST, потому что клиент отправляет данные для вычисления.
  • URL: полный адрес, например http://localhost:8001/api/calculator/add.
  • Path: часть URL без домена и порта, например /api/calculator/add.
  • Headers: служебные подсказки. Header Content-Type: application/json говорит серверу, что body написан в JSON.
  • Body и headers - разные вещи. Body несёт данные калькулятора, headers объясняют, как эти данные читать.
  • Body: данные запроса. Для сложения это {"a": 10, "b": 5}.

Из чего состоит HTTP response

  • Status code: короткий результат запроса. 200 значит успех, 400 - ошибка в данных клиента, 422 - JSON не прошёл проверку Pydantic.
  • Headers: служебная информация ответа. В главе middleware добавляет header X-FastAPI-Book-Chapter: 01.
  • Body: полезные данные ответа. В успешном калькуляторе это JSON {"result": 15, "operation": "add"}.

Headers подробнее

Header - это пара name: value. Например: Content-Type: application/json. Имя header-а говорит, о какой настройке речь, а значение даёт конкретную информацию.

Request headers отправляет клиент. В этой главе клиент отправляет Content-Type, а браузер или curl также могут отправить User-Agent.

Response headers отправляет сервер. Uvicorn добавляет технический header server: uvicorn, FastAPI добавляет content-type: application/json, а наш middleware добавляет x-fastapi-book-chapter: 01.

Headers часто не видны на странице, потому что браузер показывает body. Чтобы увидеть их руками, используйте curl -i: он печатает status line, headers и body.

  • Content-Type - формат body. Для JSON обычно application/json.
  • Accept - какой формат ответа клиент хотел бы получить.
  • Authorization - header для token-а. Он подробно появится в главах про JWT.
  • User-Agent - кто делает запрос: браузер, curl, мобильное приложение или другой клиент.
  • X-... - часто так называют свои custom headers, например X-Demo-Client или X-FastAPI-Book-Chapter.

Зачем нужен Uvicorn

FastAPI - это framework для описания приложения: какие есть endpoint-ы, какие модели данных, какая документация и какая логика выполняется.

Но объект app = FastAPI() сам не открывает порт и не принимает сетевые запросы. Для этого нужен ASGI-сервер. В нашем проекте это Uvicorn.

Когда вы запускаете uvicorn chapter01.app.main:app --reload --port 8001, Uvicorn импортирует Python-модуль, берёт переменную app, слушает порт 8001 и передаёт запросы в FastAPI.

Если совсем коротко: Uvicorn - это дверь с улицы в ваше FastAPI-приложение.

Как проходит запрос

  1. Вы запускаете сервер командой uvicorn chapter01.app.main:app --reload --port 8001.
  2. Uvicorn импортирует модуль chapter01.app.main и находит в нём переменную app.
  3. Uvicorn начинает слушать порт 8001. Это значит: он ждёт HTTP-запросы на http://localhost:8001.
  4. Клиент отправляет POST /api/calculator/add с header Content-Type: application/json и body {"a": 10, "b": 5}.
  5. Uvicorn принимает сетевой запрос и передаёт его FastAPI-приложению через ASGI.
  6. FastAPI смотрит на method POST и path /api/calculator/add, затем выбирает функцию add.
  7. Перед вызовом функции FastAPI читает JSON body и просит Pydantic собрать CalculationRequest.
  8. Pydantic проверяет, что поля a и b есть и являются числами. Если нет - FastAPI вернёт 422, не заходя в endpoint.
  9. Endpoint получает готовый объект request и возвращает обычный Python-словарь.
  10. Middleware добавляет заголовок X-FastAPI-Book-Chapter: 01 в ответ.
  11. FastAPI превращает словарь в JSON, выставляет status code 200, а Uvicorn отправляет ответ клиенту.

Полный учебный код приложения

{% raw %}from pathlib import Path
from typing import Annotated

from fastapi import FastAPI, Header, HTTPException, Request
from fastapi.responses import HTMLResponse, RedirectResponse
from fastapi.staticfiles import StaticFiles
from fastapi.templating import Jinja2Templates
from pydantic import BaseModel


BASE_DIR = Path(__file__).resolve().parent.parent

app = FastAPI(
    title="Глава 1: FastAPI basics",
    description="Middleware, REST API, OpenAPI",
    version="1.0.0",
    docs_url="/docs",
    redoc_url="/redoc",
)
app.mount("/static", StaticFiles(directory=str(BASE_DIR / "static")), name="static")
templates = Jinja2Templates(directory=str(BASE_DIR / "templates"))


@app.get("/", response_class=HTMLResponse, include_in_schema=False)
async def index(request: Request):
    return templates.TemplateResponse(request, "index.html", {"request": request})


@app.get("/swagger", include_in_schema=False)
async def swagger():
    return RedirectResponse(url="/docs")


class CalculationRequest(BaseModel):
    a: float
    b: float


@app.middleware("http")
async def add_lesson_header(request, call_next):
    response = await call_next(request)
    response.headers["X-FastAPI-Book-Chapter"] = "01"
    return response


@app.post("/api/calculator/add")
async def add(request: CalculationRequest):
    return {"result": request.a + request.b, "operation": "add"}


@app.post("/api/calculator/subtract")
async def subtract(request: CalculationRequest):
    return {"result": request.a - request.b, "operation": "subtract"}


@app.post("/api/calculator/multiply")
async def multiply(request: CalculationRequest):
    return {"result": request.a * request.b, "operation": "multiply"}


@app.post("/api/calculator/divide")
async def divide(request: CalculationRequest):
    if request.b == 0:
        raise HTTPException(status_code=400, detail="Деление на ноль невозможно")
    return {"result": request.a / request.b, "operation": "divide"}


@app.get("/api/headers/demo")
async def headers_demo(
    user_agent: Annotated[str | None, Header()] = None,
    x_demo_client: Annotated[str | None, Header()] = None,
):
    return {
        "user_agent": user_agent,
        "x_demo_client": x_demo_client,
        "note": "Response header X-FastAPI-Book-Chapter добавляет middleware.",
    }


if __name__ == "__main__":
    import uvicorn

    uvicorn.run("chapter01.app.main:app", host="127.0.0.1", port=8001, reload=True){% endraw %}

Если совсем по-простому

Эта глава показывает не только endpoint-ы, а весь минимальный backend-сервис: файл приложения, объект app, сервер Uvicorn, REST-запросы, JSON и ответы.

Представьте обычный сайт: браузер просит HTML-страницу. REST API работает похоже, но вместо HTML чаще возвращает JSON, чтобы данные мог читать frontend, мобильное приложение или другой backend.

FastAPI не запускается сам по себе как отдельная программа. FastAPI описывает приложение, а Uvicorn поднимает сервер, слушает порт и передаёт запросы в FastAPI.

Главная цепочка этой главы: клиент отправил HTTP request → Uvicorn принял запрос → FastAPI нашёл endpoint → Pydantic проверил JSON → функция вернула словарь → клиент получил HTTP response.

Если вы только начинаете Python: двоеточие : открывает блок кода, а отступы показывают, какие строки относятся к классу, функции или условию.

Построчный разбор

from typing import Annotated
Импортируем способ добавить к типу Python подсказку FastAPI. Ниже он нужен для чтения headers.
from fastapi import FastAPI, Header, HTTPException, Request
Импортируем основные инструменты FastAPI: само приложение, чтение header-ов, ошибку HTTP и объект запроса для HTML-страницы.
from pydantic import BaseModel
Импортируем базовый класс Pydantic. Он нужен, чтобы описывать и проверять JSON от клиента.
BASE_DIR = Path(__file__).resolve().parent.parent
Находим папку главы. Это нужно для подключения шаблонов и static-файлов, чтобы страница урока открывалась в браузере.
app = FastAPI(...)
Создаём объект приложения. Именно его Uvicorn будет запускать и именно в нём FastAPI хранит маршруты.
docs_url="/docs"
Говорим FastAPI, где показать Swagger UI. Swagger позволяет руками отправлять запросы без отдельной программы.
redoc_url="/redoc"
Говорим FastAPI, где показать ReDoc. Это более спокойная страница документации для чтения схемы API.
app.mount("/static", ...)

templates = Jinja2Templates(...)
Готовим шаблоны, чтобы endpoint / мог вернуть HTML-страницу, а не JSON.
@app.get("/")
Регистрируем обычную HTML-страницу урока. Когда браузер открывает корень сайта, FastAPI вызывает функцию index.
@app.get("/swagger")
Делаем короткий redirect на /docs, чтобы ссылка Swagger была привычной.
class CalculationRequest(BaseModel):
Создаём класс-описание входных данных. Это не вычисление, а схема: какие поля пользователь должен прислать в JSON.
BaseModel
Базовый класс Pydantic. Благодаря ему FastAPI понимает, что тело запроса нужно проверить.
a: float
Поле a обязательно. float значит число с дробной частью или без неё: 10, 10.5, 0.
b: float
Второе обязательное число. Если пользователь пришлёт строку, которую нельзя превратить в число, FastAPI вернёт ошибку валидации.
@app.middleware("http")
Регистрируем функцию, которая оборачивает каждый HTTP-запрос. Она срабатывает и для HTML-страницы, и для REST endpoint-ов.
response = await call_next(request)
Передаём запрос дальше в FastAPI. Без этой строки endpoint не выполнится, потому что middleware остановит цепочку.
response.headers["X-FastAPI-Book-Chapter"] = "01"
Добавляем учебный HTTP header в ответ. Так видно, что middleware действительно прошёл после endpoint-а.
@app.post("/api/calculator/add")
Связываем HTTP method POST и path /api/calculator/add с функцией add.
@app.post("/api/calculator/divide")
Декоратор. Он говорит FastAPI: когда придёт POST-запрос на этот адрес, вызови функцию ниже.
async def divide(...):
Объявляем асинхронную функцию endpoint-а. async нужно, чтобы FastAPI мог эффективно обслуживать много запросов.
request: CalculationRequest
Параметр функции. FastAPI создаст объект CalculationRequest из JSON-тела запроса и положит его в переменную request.
if request.b == 0:
Обычная проверка Python: если второе число равно нулю, делить нельзя.
raise HTTPException(...)
Останавливаем выполнение функции и возвращаем клиенту ошибку HTTP 400. Это лучше, чем дать Python упасть с делением на ноль.
return {"result": ...}
Возвращаем словарь. FastAPI сам превратит его в JSON-ответ.
@app.get("/api/headers/demo")
Учебный endpoint для просмотра request headers. Его удобно открыть в Swagger и попробовать разные значения.
user_agent: Annotated[str | None, Header()]
Просим FastAPI взять header User-Agent. Если header отсутствует, значение будет None.

Просим FastAPI взять custom header X-Demo-Client. В параметре Python используется underscore, а в HTTP header - дефис.
"note": "Response header ..."
Напоминаем, что тело ответа и headers ответа - разные места. Это поле находится в JSON body, а X-FastAPI-Book-Chapter находится в response headers.
if __name__ == "__main__":
Этот блок запускается только если файл стартует напрямую командой python chapter01/app/main.py. При обычном импорте для тестов он не выполняется.
uvicorn.run(...)
Программный способ запустить тот же сервер, который обычно запускают командой uvicorn ....

Что здесь важно

  • Сам FastAPI-объект app не слушает порт. Порт слушает Uvicorn, а FastAPI описывает, что делать с запросами.
  • Строка chapter01.app.main:app читается так: импортируй модуль chapter01.app.main и возьми из него переменную app.
  • BaseModel говорит FastAPI читать тело запроса как JSON и проверять его до вызова endpoint-а.
  • Header() говорит FastAPI взять значение не из JSON body, а из HTTP headers.
  • Если поле отсутствует или тип не подходит, endpoint даже не будет вызван: FastAPI вернёт validation error.
  • HTTPException используется для ожидаемых ошибок клиента, где вы сами выбираете status code.
  • --reload нужен только для разработки: Uvicorn перезапускает приложение после изменения файлов.

Типичные ошибки новичков

  • Забыть двоеточие после class, def или if.
  • Сделать неправильный отступ: в Python отступы заменяют фигурные скобки.
  • Написать request["b"] вместо request.b. Pydantic-модель здесь используется как объект с полями.
  • Не проверить деление на ноль и получить внутреннюю ошибку сервера вместо понятного ответа 400.
  • Думать, что app = FastAPI() само открывает порт. Порт открывает Uvicorn.
  • Писать uvicorn app вместо полного пути uvicorn chapter01.app.main:app. Uvicorn должен знать, откуда импортировать объект приложения.
  • Отправлять JSON без header Content-Type: application/json в ручных curl-запросах.
  • Искать request headers внутри JSON body. Headers и body приходят в разных частях HTTP-запроса.
  • Писать в Python параметр x-demo-client. В Python нельзя дефисы в имени переменной, поэтому пишем x_demo_client, а FastAPI сопоставляет это с header-ом X-Demo-Client.
  • Путать path /api/calculator/add и полный URL http://localhost:8001/api/calculator/add. Path - это только часть после домена и порта.

{% raw %}from typing import Annotated

from fastapi import FastAPI, Header, HTTPException
from pydantic import BaseModel


app = FastAPI(
    title="Глава 1: FastAPI basics",
    description="Middleware, REST API, OpenAPI",
    version="1.0.0",
    docs_url="/docs",
    redoc_url="/redoc",
)


class CalculationRequest(BaseModel):
    a: float
    b: float


@app.middleware("http")
async def add_lesson_header(request, call_next):
    response = await call_next(request)
    response.headers["X-FastAPI-Book-Chapter"] = "01"
    return response


@app.post("/api/calculator/add")
async def add(request: CalculationRequest):
    return {"result": request.a + request.b, "operation": "add"}


@app.post("/api/calculator/subtract")
async def subtract(request: CalculationRequest):
    return {"result": request.a - request.b, "operation": "subtract"}


@app.post("/api/calculator/multiply")
async def multiply(request: CalculationRequest):
    return {"result": request.a * request.b, "operation": "multiply"}


@app.post("/api/calculator/divide")
async def divide(request: CalculationRequest):
    if request.b == 0:
        raise HTTPException(status_code=400, detail="Деление на ноль невозможно")
    return {"result": request.a / request.b, "operation": "divide"}


@app.get("/api/headers/demo")
async def headers_demo(
    user_agent: Annotated[str | None, Header()] = None,
    x_demo_client: Annotated[str | None, Header()] = None,
):
    return {
        "user_agent": user_agent,
        "x_demo_client": x_demo_client,
        "note": "Response header X-FastAPI-Book-Chapter добавляет middleware.",
    }


@app.post("/api/calculator/power")
async def power(request: CalculationRequest):
    return {"result": request.a ** request.b, "operation": "power"}


if __name__ == "__main__":
    import uvicorn

    uvicorn.run("chapter01.app.main:app", host="127.0.0.1", port=8001, reload=True){% endraw %}
